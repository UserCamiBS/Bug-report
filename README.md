# 🧪 QA Analysis | EBAC Shop - E-commerce Testing

Projeto desenvolvido como parte da formação em **Qualidade de Software (QA)** na EBAC, com foco na aplicação prática de testes manuais, identificação de falhas e proposta de melhorias em um sistema real.

---

## 🎯 Objetivo

Avaliar o e-commerce de teste da EBAC, identificando:

- ✔️ Bugs funcionais
- ✔️ Problemas visuais
- ✔️ Oportunidades de melhoria
- ✔️ Inconsistências de usabilidade

Aplicando o modelo profissional de **Bug Report**, com rastreabilidade e evidências.

🔗 Sistema testado:  
http://lojaebac.ebaconline.art.br/

---

## 🛠️ Abordagem de Teste

Durante a análise foram aplicadas as seguintes práticas:

- Teste funcional
- Teste exploratório
- Teste visual
- Validação de fluxo de navegação
- Verificação de consistência de idioma
- Registro estruturado de bugs
- Documentação com evidências

---

## 🐞 Bugs Identificados

### 🔴 B001 — Imagens de produtos não carregam
- Tipo: BUG
- Severidade: Alta
- Impacto: Compromete a experiência do usuário e decisão de compra
- Evidência registrada no documento oficial

### 🔴 B002 — Funcionalidade de comparação de produtos não funciona
- Tipo: BUG
- Severidade: Média
- Impacto: Funcionalidade crítica indisponível para o usuário
- Evidência registrada no documento oficial

---

## 💡 Melhorias Propostas

### 🟡 M001 — Falta de destaque visual ao passar o mouse (hover)
- Tipo: MELHORIA
- Impacto: Dificulta a identificação de elementos interativos

### 🟡 M002 — Inconsistência de idioma (Português/Inglês)
- Tipo: MELHORIA
- Impacto: Quebra de padrão e possível confusão ao usuário
